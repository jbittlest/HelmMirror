How to use it
  1. Phone and Mac both on the same Wi-Fi (on the boat: the plotter's).
  2. On the Mac run swift run helmbridge — it prints an address.
  3. Type that address above, tap Connect.
  4. First time: on the plotter approve HelmMirror under Settings ▸ Communications ▸ Wi-Fi Network ▸ Wi-Fi Devices ▸ "View and Control".
