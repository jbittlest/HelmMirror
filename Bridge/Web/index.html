Getting connected
  1. Join your phone to the plotter's Wi-Fi — the same one the Mac is on.
  2. On the Mac, run swift run helmbridge. It prints an address.
  3. Type that address above and tap Connect.
  4. First time only: on the plotter, approve this device under Settings ▸ Communications ▸ Wi-Fi Network ▸ Wi-Fi Devices ▸ "View and Control".
Heads up: this page is loaded over HTTPS, and browsers block HTTPS pages from talking to a plain-HTTP device on your local network. Tap Connect and it will reopen the app directly from the bridge, which works. For the best experience, open the bridge address itself and use Share ▸ Add to Home Screen from there.
